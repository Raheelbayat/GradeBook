# My Project Title: GradeBook

## Who is the code writer of this Project?
Raheel Bayat.

##Functions of GradeBook:
This project is a small Student Gradebook & Course Manager. The program helps manage students,
courses, assessments, and grades.
The project should follow this general flow:
1. Add students: First, the user adds students to the system. Each student should have a student ID,
name, and email.
2. Add courses: Next, the user adds courses. Each course should have a course code and course name.
3. Enroll students in courses: After students and courses are created, the user can connect a student
to a course.
4. Add assessments to a course: The user can add graded work such as quizzes, exams, or projects to a
course.
5. Record student grades: After assessments are added, the user records each student's score.
6. Calculate averages: The program calculates the student's average grade in a course.
7. Show student report: Finally, the program shows a clear report with grades, average, and pass/fail
result.

## How to run the project?
It is super simple. You have to first download and install Python software if it is npt already downloaded.
Then, open the app and open the main.py or Gradebook.py file-based on the existing format-file. Then click 
on the run button on the top border revealing by a triangle.
